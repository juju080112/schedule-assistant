# 日程助手

一个本地优先的 Android 日程应用：**AI 把一段通知/截图/文件解析成日程**，并把**大学教务系统的课表**同步成一条条独立日程，准点提醒。

> 本项目为个人开源项目，**与任何高校官方无关**，未获得也未暗示任何学校的背书；项目中不含任何学校标识素材。请勿使用校名、校徽等标识性素材二次分发本项目。

---

## 功能

### ⏰ 日程
- 待办与课程合并成一条时间线，按天分组、天内按时间排序
- 每张卡片：左上角圆圈=标记完成，右上角叉=删除；点卡片看详情
- 提醒：**开始时准点提醒 + 开始前 1 小时预提醒**
- 常驻通知栏/锁屏的「今日日程栏」，可显示「正在上课 · 08:00-09:35 高等数学 @二教101」

### ✨ 智能解析
- 输入可以是**文字 / 图片 / 文件**（PDF、Word、txt、md、csv、json）
- 图片在本机压缩后交给视觉模型；PDF、DOCX 在本机抽取文本
- 输出结构化日程（标题、备注、时间、是否提醒），可逐条增删后再保存
- 同一条活动重复解析会**自动合并**成一条，详情取两次的并集

### 📅 课程表
- 从教务系统**只读**同步整学期课表，渲染成周课表网格（可翻周、本周高亮）
- **逐周正确**：按教务返回的周次数据展开，不同周次的课不同
- 每节课会被展开成**独立日程**，可单独完成、单独删除、单独清理
- 课表临时调整后，重新同步会**自动对账**：时间/地点变化就地更新、取消的删除、新增的补建
- 每天定时后台静默同步一次，滚动续排未来 3 天的提醒

### 💬 AI 助手
- 用一句话增删改查日程（新增/修改/完成/恢复/删除/清空/统计）
- 对话历史仅存本机

### ⚙️ 设置
- **外观**：浅色 / 深色 / 跟随系统
- AI 配置、课表同步、通知与提醒、**使用指南**（权限自检 + 各品牌后台设置引导）、数据管理

## 隐私说明

- **没有自建服务器**，不收集、不上传任何数据；日程、课表、对话历史、API Key 全部只存本机
- 教务同步为**只读接入**：仅请求课表数据，**零写操作**；登录由用户在系统浏览器内核中亲手完成，应用**不读取、不存储**账号、密码、Cookie、Token；登录会话仅保留在本机内核内、仅供自动同步复用，可一键清除
- AI 解析的请求直连模型服务商（默认智谱 GLM），使用**用户自己的 API Key**；请求内容不经过本项目作者
- 提供「一键清理已完成」与「清空所有数据」入口

## 构建

### 环境
- Node.js 18+、JDK 17、Android SDK（`compileSdk 35`，需 build-tools）
- 无需 Android Studio，命令行即可出包

### 步骤

```bash
# 1. 安装依赖
npm install

# 2. 同步网页层到原生工程（改了 www/ 之后必须执行）
npx cap sync android

# 3. 构建
cd android
./gradlew assembleRelease        # Windows: gradlew.bat assembleRelease
```

产物：`android/app/build/outputs/apk/release/app-release.apk`

### 签名（可选）

仓库不含签名密钥。未配置签名时，release 包会自动回落到 debug 签名，仍可直接构建安装。

要出正式签名包：

```bash
cp android/keystore.properties.example android/keystore.properties
# 填入你自己的 keystore 路径与口令
```

然后把自己的 keystore 放到 `android/app/` 下（该目录下的 `*.keystore` 已在 `.gitignore` 中）。

## 技术栈

- **前端**：原生 HTML / CSS / JavaScript（无框架）
- **打包**：Capacitor 6（混合应用）
- **原生层**（Java）：教务登录与只读抓取窗口、每日后台同步服务、课程提醒精确闹钟、常驻通知栏服务、开机续排、主题同步
- **数据**：网页层 `localStorage` + 原生 `SharedPreferences`
- **提醒**：本地通知 + `AlarmManager` 精确闹钟（`setExactAndAllowWhileIdle`，无权限时自动降级）

---

## 已知限制

- 课程同步目前只适配**中国科学技术大学新版教务系统**（`jw.ustc.edu.cn`）的课表数据结构；其他学校需要改 `www/js/course-ustc.js` 的解析部分
- 日程界面中的课程条目在「当天 + 3 天」窗口内生成，需要应用运行才会滚动更新（提醒由原生侧负责，不依赖应用是否打开）
- 各厂商 ROM 的省电策略可能拦截后台同步与提醒，请在「设置 → 使用指南」中按品牌放行
